# One Second

Магазин наручных часов: витрина, каталог 14 брендов, 28 моделей и 57 вариантов, фильтры, избранное, корзина и запрос цены в WhatsApp. Фотографии отображаются на прозрачном фоне.

- Магазин: https://one-second.u-dakaev2016.chatgpt.site
- Админская панель: https://one-second.u-dakaev2016.chatgpt.site/admin

## Админская панель

Владелец управляет товарами, цветами, фотографиями, ценами, наличием, публикацией моделей, брендами и контактами. Данные сохраняются в Cloudflare D1; загруженные фотографии — в R2. Изменения защищены проверкой владельца, проверкой Origin и версией каталога.

Авторизация через ChatGPT предоставляется хостингом Sites. При первом входе владелец определяется сервером по разрешённому email в `lib/catalog.ts`, после чего доступ привязывается к стабильному ID пользователя этого сайта.

## Структура

- `app/route.ts`, `lib/storefront.ts` — главная страница.
- `public/` — стили, клиентский JavaScript и фотографии.
- `lib/admin.html`, `public/admin.js`, `public/admin.css` — админская панель.
- `app/api/catalog/` — каталог магазина.
- `app/api/admin/` — защищённые операции сохранения и загрузки фото.
- `app/uploads/` — выдача фотографий из R2.
- `lib/seed.json` — исходный каталог со ссылками на источники моделей.
- `lib/catalog-validation.ts` — серверная проверка данных.
- `db/`, `drizzle/` — схема D1 и миграции.
- `.openai/hosting.json` — идентификатор сайта и привязки D1/R2.

## Разработка

Нужны Node.js >= 22.13 и pnpm (версия указана в `package.json`).

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

Проект использует Vinext, Vite и Cloudflare Workers. Скрипты учитывают среду Sites; для разработки вне Sites применяется portable-профиль. Локальные миграции D1 описаны в `docs/runtime.md`.

Для хостинга вне Sites необходимо отдельно настроить Cloudflare D1/R2 и адаптировать авторизацию: одного статического GitHub Pages недостаточно для админской панели и серверных API.

## Публикация и данные

Этот репозиторий содержит исходный код текущей опубликованной версии и встроенный каталог. Изменения в GitHub автоматически не публикуются на текущий сайт: нужна отдельная сборка и публикация через Sites.

Рабочая база D1, загруженные через админку файлы R2, cookies и секреты хостинга не хранятся в Git. Копию актуального каталога можно скачать кнопкой в админской панели. Все исходные фотографии встроенного каталога включены в `public/assets/catalog/`; ссылки на источники указаны в `lib/seed.json`.

## Проверки

Сборка и TypeScript прошли. Проверены ограничения доступа владельца, CSRF/Origin, сохранение цен, конфликт версий, скрытие товаров и отклонение небезопасных URL. Также проверены фильтры каталога, выбор разных цветов в корзине и прозрачность всех 57 фотографий. Полная браузерная проверка не выполнялась.
