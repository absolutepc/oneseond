# One Second

Независимый интернет-магазин наручных часов. Запускается на **Cloudflare Workers + D1 + R2** в вашем аккаунте и может работать на вашем домене. Аккаунт ChatGPT для посетителей и администратора не нужен.

В репозитории: полный исходный код витрины и административной панели, каталог 14 брендов / 28 моделей / 57 вариантов, локальные изображения часов, фильтры, выбор цвета, избранное, корзина, контакты и мобильная навигация. Сохранены последние изменения дизайна из `main`, включая центрированное название магазина и тёмно-синюю палитру.

## Быстрый старт

Нужны Node.js >= 22.13, pnpm 11.25.0 и аккаунт Cloudflare с Workers, D1 и R2.

```sh
pnpm install --frozen-lockfile
pnpm exec wrangler login
pnpm exec wrangler d1 create one-second-db
pnpm exec wrangler r2 bucket create one-second-photos
```

Замените пример `database_id` в `wrangler.jsonc` на ID созданной базы. Если выбрали другие имена ресурсов, исправьте и их. Имена привязок `DB` и `BUCKET` сохраняйте.

Подробная инструкция: **[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)**. В ней описаны пароль администратора, миграции, запуск, домен и перенос данных.

## Админ-панель

- `/admin/login` — вход: логин `admin`, ваш собственный пароль.
- `/admin` — товары, цвета, фото, цены, наличие, бренды и контакты.
- `/admin/security` — смена пароля с завершением всех сеансов.

Пароли хешируются с индивидуальной солью (PBKDF2-SHA256). Серверные сессии действуют 8 часов; случайные токены в D1 также хранятся только в виде хешей. Cookie: HttpOnly, Secure, SameSite=Strict. Выход отзывает сессию. Мутации защищены проверкой Origin; сохранение каталога — проверкой версии. Ограничение входа: 20 попыток за 15 минут на учётную запись.

Ни пароль, ни секреты Cloudflare в репозиторий не входят. Инициализация аккаунта разрешена только через серверный секрет `ADMIN_INITIAL_PASSWORD_HASH`; открытой регистрации нет.

## Код

- `lib/storefront.ts`, `public/` — витрина, стили, JavaScript и изображения.
- `lib/seed.json` — начальный каталог.
- `lib/admin.html`, `public/admin.*` — административный интерфейс.
- `lib/admin-auth.ts`, `app/api/admin/` — пароль, сессии и защищённые API.
- `db/`, `drizzle/` — схема и миграции D1.
- `worker.ts`, `vite.config.ts`, `wrangler.jsonc` — независимая сборка и размещение.

Исторические `.openai/`, `build/sites-*`, `app/chatgpt-auth.ts`, `scripts/sites-*` и `docs/runtime.md` сохранены как исходные материалы прежнего размещения. Текущая конфигурация их не использует для входа или публикации. Для нового размещения используйте только `docs/DEPLOYMENT.md`.

## Что не переносится через Git

Рабочая база старого сайта и загруженные пользователем файлы R2 не являются исходным кодом. Их надо переносить отдельно, если каталог редактировался после создания. Все встроенные фотографии есть в `public/assets/catalog/`. Экспорт/импорт описан в инструкции.

GitHub хранит код; `git push` сам по себе сайт не публикует. GitHub Pages или обычного статического хостинга недостаточно для серверной админ-панели. Для другого провайдера, например VPS, потребуется адаптация D1/R2 и Worker-среды. Существующий адрес ChatGPT этим репозиторием автоматически не обновляется и не отключается.
